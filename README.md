# iriswall

Лёгкий демон обоев для Hyprland на Rust: `wlr-layer-shell` + EGL/GLES3.
Новые обои плавно разворачиваются кругом из центра экрана.

- вне анимации демон спит: 0% CPU/GPU, кадры не рисуются
- анимация идёт по `wl_surface.frame` (в такт монитору), прогресс считается по времени
- обои берутся из папки, текущие хранятся в конфиге
- дробный масштаб (fractional-scale + viewporter), несколько мониторов, hotplug
- декодирование в отдельном потоке, картинка заранее уменьшается под монитор

## 1. Зависимости (Arch)

```bash
sudo pacman -S --needed rust base-devel pkgconf wayland mesa libglvnd
```

## 2. Сборка и установка

```bash
cd iriswall
cargo build --release
install -Dm755 target/release/iriswall ~/.local/bin/iriswall
```

`~/.local/bin` должен быть в `PATH`.

## 3. Hyprland

В `~/.config/hypr/hyprland.conf`:

```ini
exec-once = iriswall

bind = SUPER, W, exec, iriswall next
bind = SUPER SHIFT, W, exec, iriswall prev
bind = SUPER CTRL, W, exec, iriswall random
```

Убери другие демоны обоев (hyprpaper, swww) и фон из Quickshell, иначе они
будут рисовать на том же слое.

## 4. Первый запуск

```bash
mkdir -p ~/Pictures/Wallpapers      # положи туда картинки
iriswall                            # в терминале, чтобы увидеть ошибки
```

При первом запуске создаётся `~/.config/iriswall/config.toml`.
Если `current` пуст или файла нет, берётся первая картинка из папки.

## 5. Команды

```
iriswall               запустить демон (то же, что iriswall daemon)
iriswall next | prev   следующие / предыдущие обои из папки (по имени файла)
iriswall random        случайные обои
iriswall set <файл>    поставить конкретную картинку
iriswall effect <имя>  эффект перехода: random, iris, sweep, ripple, mosaic, zoom, ink
iriswall reload        перечитать конфиг и папку
iriswall status        состояние демона
iriswall quit          остановить демон
```

## 6. Конфиг `~/.config/iriswall/config.toml`

| параметр        | по умолчанию           | описание |
|-----------------|------------------------|----------|
| `dir`           | `~/Pictures/Wallpapers`| папка с обоями (jpg, png, webp, bmp, gif; без подпапок) |
| `current`       | `""`                   | текущие обои; демон обновляет строку сам, комментарии сохраняются |
| `mode`          | `fill`                 | `fill` — заполнить с обрезкой, `fit` — вписать целиком |
| `transition_ms` | `1400`                 | длительность перехода, `0` — без анимации |
| `easing`        | `ease-in-out`          | `ease-in-out`, `ease-out`, `linear` |
| `softness`      | `0.18`                 | мягкость края круга (доля половины диагонали), `0` — резкий |
| `zoom`          | `0.05`                 | новые обои стартуют увеличенными на эту долю и оседают, `0` — выкл |
| `interval`      | `0`                    | автосмена каждые N секунд, `0` — выкл |
| `random`        | `false`                | случайный порядок при автосмене и `next` |
| `background`    | `#000000`              | цвет полей (режим `fit`) и фон до загрузки картинки |

Поменял `current` вручную — выполни `iriswall reload`.

## 7. Если что-то не работает

- **не собирается `-lEGL` / `egl.pc`**: `sudo pacman -S libglvnd mesa pkgconf`
- **`libwayland-egl` не найден при запуске**: `sudo pacman -S wayland`
- **чёрный экран**: запусти `iriswall` в терминале и посмотри сообщения; проверь `echo $WAYLAND_DISPLAY`
- **«нет подходящей EGL-конфигурации»**: нужен драйвер Mesa с GLES3 (`eglinfo`)
- **«демон уже запущен»**: `iriswall quit`, либо убей процесс; старый сокет `$XDG_RUNTIME_DIR/iriswall.sock` удалится сам
- **анимация не идёт, когда монитор закрыт полноэкранным окном**: так и задумано, compositor не шлёт кадры скрытому слою; итоговые обои применятся сразу

## 8. Как устроено

- `src/main.rs`: Wayland (layer-shell, viewporter, fractional-scale), EGL, цикл событий (calloop), сокет управления
- `src/render.rs`: декодирование и GLES3-рендер; фрагментный шейдер смешивает две текстуры по радиусу круга
- `src/config.rs`: конфиг, список файлов, easing

Шейдер: радиус круга `r = t * (maxr + soft)`, маска `1 - smoothstep(r - soft, r, dist)`,
где `dist` считается от центра экрана. Новые обои дополнительно масштабируются
от `1 + zoom` до `1` для эффекта «разворота».

## 9. Эффекты перехода

При `effect = "random"` (по умолчанию) каждая смена обоев выбирает случайный эффект
из списка `effects`, один и тот же подряд не повторяется. Точка старта, угол и зерно шума
тоже случайные.

| эффект   | что происходит |
|----------|----------------|
| `iris`   | круг из центра с мягким краем, новые обои «оседают» |
| `sweep`  | мягкая волна под случайным углом, обе картинки слегка едут (параллакс) |
| `ripple` | круг от случайной точки с кольцом-рябью, преломляющим картинку |
| `mosaic` | плитки проявляются волной от случайной точки, каждая оседает с зумом |
| `zoom`   | кроссфейд с радиальным размытием, как «пролёт» сквозь картинку |
| `ink`    | органичное растекание по шуму от случайной точки с тёмной кромкой |

Зафиксировать один эффект: `effect = "ripple"` в конфиге или `iriswall effect ripple`
(до перезапуска демона). Ограничить выбор: `effects = ["iris", "ink", "zoom"]`.
